# Goose Recipes

Reusable Goose agent recipes, organized by use case.

## Structure

- `recipes/content/` — Content creation workflows (blog posts, social, copy)
- `recipes/sales/` — Sales research, outreach, and analysis workflows
- `recipes/research/` — General research and summarization workflows

## How to run a recipe

```bash
goose run goose/recipes/<category>/<recipe-name>.yaml
```
